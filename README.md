# 2048 游戏

经典的2048数字合并游戏，使用纯HTML/CSS/JavaScript实现。

## 🎮 游戏玩法

- 使用键盘方向键（↑↓←→）或WASD键控制方块移动
- 手机端支持触屏滑动手势
- 相同数字的方块相撞时会合并成它们的和
- 目标：合并出2048方块！

## ✨ 功能特性

| 功能 | 描述 |
|------|------|
| 🎯 计分系统 | 实时显示当前分数，最高分自动保存到本地存储 |
| 📊 难度选择 | 4种难度：简单(3×3)、普通(4×4)、困难(5×5)、专家(6×6) |
| ▶️ 游戏控制 | 开始、暂停、重开按钮 |
| 🎨 主题皮肤 | 4套精美主题：经典、日落、海洋、森林 |
| 🖼️ AI背景 | 根据主题自动切换精美背景图片 |
| ✨ 动画效果 | 方块出现、合并、浮动分数等动画 |
| 🔊 音效系统 | Web Audio API实现的游戏音效 |
| 🏆 本地排行榜 | Top 10高分记录 |
| 🎬 操作回放 | 回放上一局游戏的所有操作 |
| 📱 响应式设计 | 完美适配桌面和移动端 |

## 🛠️ 技术栈

- **HTML5** - 页面结构
- **CSS3** - 样式和动画
- **JavaScript ES6+** - 游戏逻辑
- **Web Audio API** - 音效系统
- **LocalStorage** - 数据持久化
- **Touch Events API** - 触屏支持

## 📝 开发说明

### 核心类：Game2048

主要方法：
- `init()` - 初始化游戏
- `move(direction)` - 处理方块移动和合并
- `addRandomTile()` - 添加随机方块
- `render()` - 渲染游戏界面
- `checkGameState()` - 检查游戏状态（胜利/失败）
- `playSound(type)` - 播放音效
- `saveToLeaderboard()` - 保存分数到排行榜
